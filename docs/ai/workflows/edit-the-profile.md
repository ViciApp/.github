# Edit the org profile

`profile/README.md` is the public front page at github.com/ViciApp.

1. Keep the shape: the one-line tagline, the short pitch, the link to vici.market, the "How it is built" table (layer, what, repository link) and the closing line on what runs on-chain and off-chain.
2. Link repositories by full URL; a private repository's link only works for org members, so list public ones.
3. Ask the owner before changing what the profile says about the product. Fixing a typo or a broken link needs no ask ([governance](../governance.md#without-asking-and-not)).
4. Preview the Markdown, then open the pull request with a `docs(profile): ...` title.
